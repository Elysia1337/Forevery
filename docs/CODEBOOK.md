# Forevery 情绪码表 v0.1

> 全局一份，预建。符号一旦分配**永久不改、只增不重用**。
> 宽泛词（高兴、不开心、生气、难受）**不进库**；它们只作口语映射，检索时落到下面的细节点。

## 一、坐标怎么读

每个情绪是一个点，三个数：

| 轴 | 含义 | 范围 |
|---|---|---|
| `v` | 好不好受（效价） | −5（极难受）… +5（极好受） |
| `a` | 强不强（唤醒） | 0（平）… 5（炸） |
| `t` | 冲谁（指向） | +1 对自己 / −1 对别人 / 0 都有或说不清 |

**阳面 = 对自己，阴面 = 对别人。** 例：

| 情绪 | v | a | t |
|---|---|---|---|
| 得意 | +4 | 2 | +1 自己 |
| 自责 | −3 | 3 | +1 自己 |
| 委屈 | −3 | 3 | −1 别人 |
| 感激 | +4 | 2 | −1 别人 |
| 心疼 | −3 | 2 | −1 别人 |
| 中性 | 0 | 0 | 0 |

`t` 记的是**情绪冲谁**，不是动作落在谁身上：『我等你』的牵挂冲对方（−1），『等』这个动作落在自己身上不影响 `t`；实在说不清才用 0。

## 二、符号规则

```
~大类字母 + 3 位节点号 - 强度~
```

- 大类：`L` 乐 / `H` 好 / `N` 怒 / `A` 哀 / `J` 惧 / `E` 恶 / `G` 惊 / `Z` 中性。
- 强度：1–5，1 最轻、5 最重。
- 一句最多 3 个码，**主码在前**；同句多码用空格隔开。
- 纯任务指令**不打码、不进库**。
- 非任务、又确实读不出情绪的句子，打 `~Z000-0~`。
- 特殊列 `X` 预留，暂不启用（用于多模态判不了、或用户句 < 40 字且无情绪时的兜底）。

例：

```
……我看了好一会儿，觉得那画里的孩子像她，也像我看着的她。~A014-2~ ~L014-2~
```

### X 特殊列（预留，暂不启用）

- 用途 1：多模态判不了，前文也继承不到。
- 用途 2：用户句 < 40 字且无明显情绪，继承失败。
- 只记原文指针 + 原因，不编情绪码；检索时单独一路。

## 四、维护规则

1. 新增节点只能往后编号，**不复用**已删/废弃的号。
2. 改定义不改符号；符号与定义绑定，定义要修正时加 `rev` 字段，保留旧定义。
3. 宽泛词不进库；口语映射表另放（v0.2 再做）。
4. 一个符号一义；多义拆节点。
5. 坐标可随经验库校准，但每次校准要记版本号。
