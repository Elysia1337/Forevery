# 暂停词与收尾词

默认是中文；换语言请改 `src/triggers.mjs`。

## 收尾词（触发打标）

- 晚安、明天见、先睡了、睡了、再见、先这样、先聊到这、我去忙、回头说、下了、拜拜、886、我走了、不聊了、关机、关电脑；
- 辛苦你了、完工、收工、落库、今天到这儿、今天先到这、先到这。

消息长度 ≤ 40 字才算，避免长文里夹一句“完工”误触发。

## 暂停词

| 词 | 效果 |
|---|---|
| `先别记` / `暂停记忆` / `暂时别记` / `先不记` / `停止记录` | 停原文 + 停自动打标 |
| `暂停收尾` / `先别落库` / `晚点再收` | 只停自动打标，原文继续 |
| `继续记忆` / `接着记` / `恢复记录` / `可以记了` | 恢复 |

暂停状态持久化在 `control.json`，按会话 key 区分。

## 静默窗

收尾后：

- 睡觉类词（晚安/明天见/先睡了）→ 8 小时；
- 工作类词（完工/收工/辛苦你了）→ 45 分钟；
- 用户再说话立即清除。

主动搭话的发送方必须先查 `isQuiet(key)`；否则会跟“刚收尾”打架。

## 注意

- 暂停不是删除；已落库内容不自动删。
- 暂停只影响当前会话 key；不同会话互不影响。
- 收尾词是提示，不是保证；崩溃还要靠原文层和恢复。
