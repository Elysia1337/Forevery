# 最小检索器

`forevery/retrieval` 只做示例和基准，不是生产检索引擎。

```js
import { search } from 'forevery/retrieval';

search(records, {
  text: '谢谢晚饭',
  codes: ['H009-2'],
  entities: ['爸爸', '晚饭'],
  scenes: ['晚饭'],
  focus: 'Alice',
  top: 3,
});
```

- 有码时：码 0.5、文本 0.3、场景 0.1、实体 0.05、focus 0.05；
- 无码时：文本 0.4、实体 0.3、场景 0.15、focus 0.15；
- `tombstone` / `superseded_by` 自动过滤；
- 中文按 1–2 字切，英文按词。

## 边界

- 没有向量、没有模型、没有查询改写；
- 不代表真实召回质量；
- 生产环境应换成自己的多路召回（原文/向量/P-C/时间/关系）；
- 它只用于 golden 回放和快速验证。

## 模糊旧事模式

查询里出现「以前/那次/那时候/旧事/旧记忆/不好的经历/难受的事/不想提/阴影/那件事/之前那/后来那/模糊」时，会自动切到 `vague`：

- 不拿情绪码做硬门槛；
- 权重改成事件 0.5、实体 0.2、场景 0.1、人物 0.1、码 0.1；
- 不设最低分，直接返回前三候选；
- 只给候选，不替你断定是哪件；要精确，得补一句事件线索。

这是为了处理「深情语境里突然想起一段不好的经历，但说不出具体哪件」。
