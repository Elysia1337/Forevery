# 新会话接上：手动版

有些客户端不会自动读项目文件。那就用这一份，在每次新会话第一句发给模型：

```text
先读 <你的最新收尾文件>，再回我；读不到就说读不到，不要猜。
```

## 为什么需要它

- 自动读文件是客户端能力，不是模型能力；
- 客户端不读，模型就不知道有这份文件；
- 这段提示只负责把入口递过去，不改变记忆内容。

## 可选的自动做法

- Claude Code：把 `templates/CLAUDE.md` 复制到项目根，改名 `CLAUDE.md`；
- Codex 一类：复制 `templates/AGENTS.md` 到项目根，改名 `AGENTS.md`；
- 其他客户端：查它有没有“项目说明/自定义指令”，有就指向同一份文件；
- 都没有：每次第一句用上面的手动版。
